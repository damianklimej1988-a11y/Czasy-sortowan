#PORÓWNANIE ALGORYTMÓW SORTOWANIA

Projekt w języku C++ porównujący działanie algorytmów Bubble Sort oraz Quick Sort.

Program generuje 50 000 losowych liczb, sortuje je za pomocą obu algorytmów i mierzy czas ich wykonania.

#OPIS PROJEKTU

Program:

Generuje 50 000 losowych liczb z zakresu 1–50 000.
Sortuje liczby za pomocą Bubble Sort.
Sortuje liczby za pomocą Quick Sort.
Porównuje czas wykonania obu algorytmów.
#ALGORYTMY
##BUBBLE SORT

Prosty algorytm polegający na porównywaniu sąsiednich elementów i zamianie ich miejscami.

Złożoność czasowa: O(n²).

##QUICK SORT

Algorytm wykorzystujący metodę „dziel i zwyciężaj”. Wybiera pivot i dzieli dane na mniejsze oraz większe elementy.

Średnia złożoność czasowa: O(n log n).
